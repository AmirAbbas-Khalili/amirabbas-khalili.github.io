# Recommendation letters

Two expandable groups: Recommendations – 2026 (two slots), Earlier Recommendations (five slots). Both start collapsed. Native details/summary supports keyboard and touch.

Fill professor, course, year, and pdf in src/data/recommendations.ts. Store PDF files under public and use a same-site path (for example /files/recommendations/letter.pdf). Populated slots show a download anchor; empty slots show a disabled button and clear placeholders. No names, earlier years, or letters are invented.

2022 group populated with five supplied courses and Scholar links. Exact displayed profile names verified directly in the browser on October 10, 2026. Vahid Shahhosseini uses Provided via Email instead of a download button. All five list 2022 and Amirkabir University of Technology; 2026 slots unchanged. PDFs for the other four remain pending.
