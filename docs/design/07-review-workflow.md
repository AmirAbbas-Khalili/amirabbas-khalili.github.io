# Review workflow

1. Basic homepage: approved bridge, original navigation/content, one-screen composition, basic typography/glass, minimal control icons. Verify build, responsive sizing, keyboard menus, and links. Stop for user review.
2. Refine user-selected typography, color and glass details. Stop for review.
3. Add tiny ambient motion if approved. Stop for review.
4. Align other page styling while preserving structure and content. Review in small groups.
5. Complete missing content one section at a time with user-provided facts/files.
6. Persian wording and right-to-left layout with user approval.
7. Final device/browser/accessibility/performance checks and deployment review.

Check responsiveness at every checkpoint, rather than saving all defects for the end. Keep normal desktop homepage one-screen; never clip links/text on small screens or zoom.
Do not implement future checkpoints silently. Record approvals and changes in this folder.
