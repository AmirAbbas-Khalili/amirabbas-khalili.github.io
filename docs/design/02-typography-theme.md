# Typography and theme

## Scope
Apply the user-provided DESIGN.md files to typography, font size/weight/line height, spacing, text colors, theme, and surface styling. They do not authorize layout or content replacements.

## Checkpoint 1 approved tokens
- Neutral/airy FlowOps foundation, confirmed by Amir.
- Self-hosted Inter Variable (explicitly specified by source guide).
- Text: #111827. Supporting text: #344c64.
- Approved bridge action accent: #085b75. Light sky/glass surfaces.
- Regular spacing rhythm: 4/8/12/16/24/32/48 px, responsive sizing.
- Name: responsive 42-80 px, weight 650; headline: 27-48 px, weight 450.
- Body: 14-16 px, relaxed line height, restrained width.
- Buttons and floating navigation are pill shaped. Dialogs have 24 px corners.
- No glowing typography, gradient text, or ornamental numeric labels.

## Reference palettes (alternatives, not simultaneously mixed)
- FlowOps: #111827, white, soft peach #FFEDD5, pale indigo #E0E7FF; Inter.
- Engage: rust #D43D17, #F4F1EA, white; Inter and JetBrains Mono labels.
- Autonomous: olive #2B3624, copper #D48C5B, #F6F3EC; Inter and Playfair Display.
- Vortex: cyan #48CAE4, charcoal #18181B; ui-sans-serif. Dark framing is optional only after user approval; approved bridge stays daylight.
- Auralis: orange #EA580C, white, charcoal #191C21; Geist and JetBrains Mono labels.

Taste Skill configuration for this project: DESIGN_VARIANCE 3, MOTION_INTENSITY 2 for basic checkpoint, VISUAL_DENSITY 3. Approved centered layout overrides the skill's high-variance defaults. Keep Astro; no framework migration.

## Confirmed by Amir
FlowOps is primary. Buttons lift subtly by 2 px on hover (Auralis influence). Autonomous warm copper is used sparingly for Home and directory headings; peach hover surfaces stay soft. Reduced-motion disables the lift.
